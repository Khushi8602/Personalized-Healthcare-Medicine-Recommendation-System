# 🏥 Personalized Healthcare & Medicine Recommendation System

An intelligent healthcare recommendation web application built with **Python, Flask, Machine Learning, Deep Learning, and Natural Language Processing (NLP)**. The system analyzes basic patient health information, generates possible disease predictions, identifies risk levels, and provides medicine suggestions and general healthcare recommendations.

The project demonstrates how machine learning and recommendation techniques can be integrated into a web-based healthcare application.

> **Important:** This is an educational and experimental project, not a medical diagnostic tool. Predictions and recommendations are not medical advice, prescriptions, or substitutes for consultation with qualified healthcare professionals.

## 📖 Project Overview

The **Personalized Healthcare & Medicine Recommendation System** is a machine learning-based web application designed to explore personalized healthcare recommendations using patient-related information.

Users can enter health details such as:

- Age
- Gender
- Blood pressure level
- Cholesterol level
- Symptoms
- Existing medical diagnosis (optional)

Based on the submitted information, the application processes the input through two prediction models:

1. **Machine Learning Model:** Support Vector Classifier (SVC).
2. **Deep Learning Model:** Artificial Neural Network built using TensorFlow/Keras.

The application combines the prediction probabilities generated by both models to rank possible conditions.

It also provides medicine suggestions based on a medicine dataset, condition-based care information, and health-related insights.

The application includes patient records and a separate insights section for exploring dataset information and model performance.

## 🎯 Problem Statement

Healthcare information and medicine-related resources can be difficult to understand without proper analysis.

Different patients have different health conditions, symptoms, and medical backgrounds. A general recommendation may not reflect individual patient information.

This project explores how machine learning algorithms and recommendation techniques can process structured health information and generate educational, data-driven suggestions.

The main objective is to build an interactive system that demonstrates:

- Patient health data processing.
- Machine learning-based disease prediction.
- Comparison of different prediction approaches.
- Medicine information matching.
- Basic healthcare risk categorization.
- Data visualization and model evaluation.

## ⚙️ How the System Works

### Step 1: Data Collection

The application uses two primary CSV datasets:

- `Cleaned_Dataset.csv` – Patient-related health records.
- `medicine.csv` – Medicine information and descriptions.

### Step 2: Data Preprocessing

The `data_processing.py` script performs data preparation activities, including:

- Loading CSV datasets.
- Handling missing values.
- Cleaning and standardizing disease names.
- Converting Yes/No symptom values into numerical representations.
- Encoding categorical features.
- Preparing model input features.
- Cleaning medicine information.

### Step 3: Exploratory Data Analysis

The project analyzes patient data to understand its characteristics and patterns.

Visualizations are generated to explore the dataset and support model evaluation.

### Step 4: Model Training

Two prediction models are trained:

**Support Vector Classifier (SVC)**

- Uses a linear kernel.
- Applies feature scaling.
- Performs multi-class disease classification.

**Artificial Neural Network**

- Developed using TensorFlow/Keras.
- Uses Dense layers and ReLU activation.
- Includes Dropout layers.
- Uses Softmax for multi-class classification.
- Trained for 30 epochs.

### Step 5: Combined Prediction

The application combines the probability outputs of both models using an average-based approach.

This produces a ranked list of possible conditions.

The individual first predictions from both models are also available on the result page.

### Step 6: Medicine Recommendation

After identifying the relevant condition, the application matches it to an available medicine category.

TF-IDF converts medicine descriptions into numerical text features.

Cosine similarity is then used to rank matching medicine entries based on the available patient-related text.

### Step 7: Healthcare Recommendation

The application retrieves general care information using predefined condition-based rules.

Additional checks consider factors such as blood pressure, cholesterol, age, and selected warning symptoms.

### Step 8: Display Results

The final results are presented through the Flask web interface.

## 🤖 Machine Learning Models

The project implements and compares two classification approaches.

### 1. Support Vector Classifier (SVC)

SVC is a supervised machine learning algorithm used for classification.

In this project:

- A linear kernel is used.
- Input features are scaled.
- The model predicts possible disease categories.
- Probability estimates are used in the combined prediction.

### 2. Artificial Neural Network

The deep learning model is implemented using TensorFlow/Keras.

Its architecture includes:

| Layer | Configuration |
|---|---|
| Input Layer | 8 features |
| Dense Layer 1 | 64 neurons, ReLU |
| Dropout | Regularization |
| Dense Layer 2 | 32 neurons, ReLU |
| Dropout | Regularization |
| Output Layer | Softmax classification |

The network is trained for 30 epochs.

### 3. Combined Prediction

The application averages the probability outputs of the two models.

This is an experimental ensemble-style approach intended to compare and combine model predictions.

It does not guarantee improved prediction accuracy.

## 💊 Medicine Recommendation Approach

The project implements a content-based text similarity approach.

**Techniques used:**

1. Disease-to-medicine category matching.
2. TF-IDF text vectorization.
3. Cosine similarity calculation.
4. Ranking medicine descriptions by similarity.

### Why TF-IDF?

TF-IDF (Term Frequency-Inverse Document Frequency) converts text into numerical features based on the importance of words within a collection of documents.

### Why Cosine Similarity?

Cosine similarity measures the similarity between numerical text vectors.

The system uses this technique to rank available medicine records based on textual relevance.

**Important:** Text similarity does not establish clinical suitability, safety, dosage, drug interactions, or effectiveness. The resulting entries are dataset matches, not prescriptions.

## 💻 Installation and Setup

Follow these steps to run the project on your local machine.

### Prerequisites

Make sure you have installed:

- Python 3.9–3.13.
- Git.
- A code editor such as Visual Studio Code.
- Internet connection for installing dependencies.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Khushi8602/Personalized-Healthcare-Medicine-Recommendation-System.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Personalized-Healthcare-Medicine-Recommendation-System
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment.

**Windows:**

```bash

```

**macOS/Linux:**

```bash
source venv/bin/activate
```

### Step 4: Install Dependencies

```bash
pip install -r requirements.txt
```

The project dependencies include:

```text
flask>=3.0
pandas
numpy
scikit-learn
joblib
matplotlib
```

Ensure the following files are available inside the `data/` directory:

Run the preprocessing and model training script:

Open your browser and visit:


## 📈 Model Evaluation

The models were evaluated using **5-fold cross-validation** on 300 unique patient records covering 114 disease categories.

The reported results are:

| Model | Top-1 Accuracy | Top-3 Accuracy |
|---|---:|---:|
| Support Vector Classifier (SVC) | 8.3% | 13.3% |
| Neural Network | 5.3% | 14.0% |
| Combined Predictions | 6.0% | 14.7% |
| Most Common Disease Baseline | 5.3% | — |

### Understanding the Results

- **Top-1 Accuracy:** Measures whether the correct disease is the model's highest-ranked prediction.
- **Top-3 Accuracy:** Measures whether the correct disease appears among the three highest-ranked predictions.

### Important Evaluation Findings

The current dataset has significant limitations:

- It contains only 300 unique records for evaluation.
- It covers 114 different disease categories.
- Many disease categories have very few records.
- Eight input features are insufficient to distinguish many different conditions reliably.

The results indicate that the current models have limited predictive performance.

These results should be considered preliminary because the models were selected using the same cross-validation results, and the neural network can vary with random initialization.

The system is therefore a learning prototype for exploring healthcare data processing, classification, and recommendation techniques rather than a clinically validated prediction system.

## ⚠️ Project Limitations

The current implementation has the following limitations:

1. **Limited Dataset:** The available patient records are insufficient for reliable multi-class disease prediction.
2. **Prediction Reliability:** Model accuracy is low, so predictions should not be used for medical decisions.
3. **Medicine Dataset:** Recommendations depend entirely on the available medicine records.
4. **Incomplete Medicine Coverage:** Some conditions do not have matching medicine categories.
5. **Risk Classification:** Risk levels are based on predefined disease-associated information, not a separately validated risk prediction model.
6. **No User Authentication:** The application currently does not implement login or user account management.
7. **No Clinical Validation:** The application has not been clinically validated.
8. **No Drug Interaction Validation:** Drug allergies, contraindications, and interactions are not comprehensively checked.
